# aws-sso-config-generator v0.4.3

## What's new

- Every release now ships `packslip.sigstore.json`, a signed list of each binary's digest, platform, and command name. This repo's release workflow signs it with its GitHub identity, and the public Sigstore transparency log records the signature. See [packslip.dev](https://packslip.dev/) for the format.

## Install with mise

With mise 2026.9.2 or later, the `packslip:` backend verifies the signature, project, version, and digest, then installs the binary for your platform:

```sh
mise use -g "packslip:github.com/djgoku/aws-sso-config-generator@0.4.3"
```

mise holds a new release back for 24 hours by default (`minimum_release_age`).

The aqua registry install from 0.4.2 still works:

```sh
MISE_AQUA_REGISTRIES=https://github.com/djgoku/aws-sso-config-generator \
  mise use -g "aqua:djgoku/aws-sso-config-generator@0.4.3"
```

## Verify a download

Download your binary and `packslip.sigstore.json` from this release, then run:

```sh
packslip verify packslip.sigstore.json \
  --pin ps1_iiyjlwltyd4utkfftgvbpsxwvq \
  --artifact aws-sso-config-generator-macos-m1
```

`ps1_iiyjlwltyd4utkfftgvbpsxwvq` is this repository's signer fingerprint. Pass the binary you downloaded as `--artifact`. Each binary also has a build provenance attestation, which `gh attestation verify <file> -R djgoku/aws-sso-config-generator` checks.

## Deprecation

- The macOS Intel (x86_64) build (`aws-sso-config-generator-macos`) will be **discontinued in a future release**. Use the `-macos-m1` build on Apple Silicon Macs.

See the full changelog <https://github.com/djgoku/aws-sso-config-generator/compare/0.4.2...0.4.3> for complete details.

### macOS downloads

A mise install needs no extra steps. If you download the macOS binary with a browser, macOS quarantines it and shows a popup:
> "Apple could not verify 'aws-sso-config-generator' is free of malware..."

Verify the binary with packslip first (see **Verify a download** above). Then clear the quarantine flag and make the binary executable. Replace `~/aws-sso-config-generator` with your download path:

```sh
xattr -dr com.apple.quarantine ~/aws-sso-config-generator
chmod +x ~/aws-sso-config-generator
```
